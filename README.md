# 射擊遊戲

固定站位的第一人稱射擊網頁遊戲第一版。

## 開啟方式

直接用瀏覽器開啟 `index.html` 即可遊玩。

線上版：

https://huangleeluang.github.io/Shot_Game/

手機第一次開啟線上版後，瀏覽器會安裝離線快取。之後可用「加入主畫面」作為全螢幕網頁 App 遊玩，已快取的版本可在離線時開啟。

## 已包含

- 主選單。
- 任務設定：關卡、難度、武器、正式 / 自訂配置。
- 三個可玩關卡：
  - 室內靶場。
  - 防守走廊。
  - 戶外狙擊場。
- 測槍牆。
- 滑鼠瞄準、左鍵射擊、右鍵開鏡、`R` 換彈、`Esc` 暫停。
- 手機橫向觸控瞄準與觸控按鈕。
- 可校準的陀螺儀瞄準。
- PWA manifest 與 service worker 離線快取。
- 專案自製 SVG 目標與武器素材。
- 三把基礎槍：手槍、步槍、狙擊槍。
- 沙盒改槍滑桿。
- 六槽配件系統。
- 每把基礎槍 3 個自訂配置槽。
- 正式成績與自訂成績分開保存。
- 設定頁：音訊、控制、畫面、語言、資料。
- 繁體中文 / 英文切換。

## 備註

第一版優先完成完整可玩流程。畫面、音效與平衡仍可繼續精修。

## 測試

```bash
node tests/aim-model.test.js
node tests/playtest-sim.test.js
node tests/pwa-assets.test.js
```

測試會確認準星固定在畫面中心、滑鼠位移會改變視角而不是移動準星、中心準星與命中判定一致，並確認陀螺儀事件會推動瞄準。模擬試玩會用玩家視角打通三關，並確認目標沒有跑出射擊安全區。PWA 測試會確認離線快取清單指向的檔案存在。
