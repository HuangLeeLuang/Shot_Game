# Game Assets

This directory contains game assets for `射擊遊戲`.

The SVG files are project-authored fallback assets.

The PNG files in `assets/ai/` are AI-generated realistic raster sprites, locally cropped and chroma-keyed into transparent PNGs.

License intent: CC0 / Public Domain dedication for the project-generated asset files in this directory.

No third-party art, sound, font, or texture files are bundled here.
